# Figures reproduced from published papers

Everything under `results/` is generated by this repository's own code and is
regenerable from it (see `notebooks/README.md`). The files here are not: they
are figures from published papers, reproduced in the thesis as quotations for
scholarly comment. Each one is cited in its thesis caption, naming the paper it
comes from.

| File | Source |
|---|---|
| `kummerer2022_dg3_fig2.png` | Kümmerer et al. (2022), *Journal of Vision* 22(5):7, Figure 2, panels (a) and (b), rendered from the paper's PDF at 400 dpi. Bib key `kummerer2022deepgaze3` |
| `judd2009_meanfixations.png` | Judd et al. (2009), *ICCV*, the mean-fixation figure, cropped to the map with the two area boxes. Bib key `judd2009mit1003` |

To re-extract at a different resolution:

```bash
pdftoppm -f <page> -l <page> -r 400 -png "<paper>.pdf" out
# then crop the panel with PIL
```
